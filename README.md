# MentalArtAI_tests

Автоматизированные smoke и негативные тесты для проверки базового сценария пользователя:
![Сценарий](./assets/Route.png)
*Ссылка на сайт: https://mentalartai.ru/*
## Стек
* Python
* httpx
* Pytest

## Что проверяют API-тесты:
1. Проверка доступности сервиса (Health Check).
2. Авторизация и регистрация тестового пользователя.
3. Возможность получения списка доступных тестов.
4. Интеграционный сценарий прохождения теста (загрузка файлов, связка бэкенда с хранилищем и ИИ-моделью).
5. Проверка невалидных значений (негативный тест)

## UI-тест полный путь пользователя от регистрации/авторизации до прохождения теста:
1. Регистрация/авторизация тестового пользователя.
2. Переход на страницу тестов.
3. Выбор теста.
4. Заполнение полей выбранного теста (категория, пол, возраст).
5. Загрузка изображения.
6. Получение результата и скачивание отчета PDF.

## Запуск
1. Создайте и заполните файл `.env`.
2. Настройте окружение:
   ```bash
   python -m venv venv
   # Linux/macOS:
   source venv/bin/activate
   # Windows: 
   venv\Scripts\activate
   pip install -r requirements.txt
   ```
3. Запустите скрипт
```bash
   # API-тест: 
   pytest tests.py
   # UI-тест: 
   pytest test_ui.py --headed

   ```
